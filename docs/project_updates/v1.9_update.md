### **Command Parsing Logic**
```python
def parse_command(self, text):
    # Check for color commands first
    for color in self.color_positions.keys():
        if color in text:
            angle = self.look_at_color(color)
            self.set_joint('head', angle)
            return

    # Check for action words
    if 'wave' in text:
        self.set_pose(self.poses['wave_right'])
    elif 'sit' in text:
        self.set_pose(self.poses['sit'])
    # ... more actions
```

### **Angle Calculation Math**
```python
def look_at_color(self, color_name):
    # Get Y position of color on table
    color_y = self.color_positions[color_name]

    # CORI at (0,0), table at (1.5, color_y)
    table_x = 1.5

    # Calculate angle using arctangent
    angle = math.atan2(color_y, table_x)

    # Clamp to joint limits
    angle = max(-1.8, min(1.8, angle))

    return angle
```

### **Background ROS2 Spinning**
```python
def run_interactive(self):
    # Start ROS2 in background thread
    spin_thread = threading.Thread(
        target=self.spin_ros,
        daemon=True
    )
    spin_thread.start()

    # Main command loop
    while self.running:
        command = input("cori> ").strip()
        self.parse_command(command)
```
